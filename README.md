# SIMARU - booking_app

[Dont forget to change baseUrl at] /lib/data/config.dart

Proses pemesanan atau reservasi ruang juga sering kali rumit dan memakan banyak waktu. Selain itu, koordinasi dan transparansi antara pihak pengelola ruang dengan pengguna ruang masih kurang, sehingga kesulitan dalam memantau penggunaan ruang secara keseluruhan. 

Untuk mengatasi permasalahan tersebut, dikembangkanlah aplikasi mobile SIMARU. Aplikasi ini bertujuan untuk memberikan kemudahan bagi pengguna dalam mendapatkan informasi ketersediaan ruang secara real-time. Proses pemesanan atau reservasi ruang juga disederhanakan melalui fitur booking yang terintegrasi. Aplikasi ini juga diharapkan dapat meningkatkan koordinasi dan transparansi antara pengelola dan pengguna ruang, serta memudahkan pemantauan penggunaan ruang secara keseluruhan bagi pihak manajemen.
